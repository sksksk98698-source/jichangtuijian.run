# 什么是机场？科学上网原理浅显科普

如果你是第一次听到“机场推荐”、“某某机场跑路了”，你可能会很纳闷：**明明是在讨论翻墙和科学上网，为什么会和飞机、机场扯上关系？**

本文将为你解开这个名词背后的来龙去脉。

---

## ✈️ 为什么叫“机场”？历史由来源起

在 2012 年，开发者 clowwindy 开发了一款开源代理工具名为 **Shadowsocks**。因为其客户端的官方图标是一架**纸飞机**，广大网民便亲切地称其为“小飞机”或“梯子”。

后来，有技术人员专门搭建了汇集几十个甚至上百个“小飞机节点”的商业化代理服务网站，集中向公众出租流量。既然一架小飞机代表一个节点，那么**停放和调度海量飞机的场所自然就被形象地称为了“机场”**。

久而久之，“机场”便成为了中文互联网中**提供多节点科学上网订阅服务商**的通用行业代名词。

---

## 🆚 机场与传统 VPN 的本质区别

很多新手容易把“机场”和传统商业 VPN（如 ExpressVPN、NordVPN）混为一谈，其实它们的技术实现完全不同：

| 对比维度 | 传统商业 VPN | 现代化“机场” (代理服务) |
| :--- | :--- | :--- |
| **底层协议** | OpenVPN / WireGuard / IPSec | Shadowsocks / Trojan / Vless / Hysteria2 |
| **抗封锁特征** | 流量指纹明显，容易被 GFW 识别并阻断 | 流量经过伪装加密，模拟正常 HTTPS 浏览流量 |
| **网络延迟** | 全球公网多跳，延迟普遍高达 200~300ms | 采用国内入口 + **IEPL 内网专线**，延迟低至 20~30ms |
| **客户端体验** | 仅能使用其官方笨重的 App | 支持 Clash、Shadowrocket 等强大的开源客户端 |
| **晚高峰体验** | 晚高峰严重降速断流 | 高端专线晚高峰丝滑跑满千兆 |

## 🧭 总结与新手建议

对于国内用户而言，传统 VPN 在当下极其强大的防火墙面前早已力不从心。**选择一家具备 IEPL 内网专线的高品质机场，搭配 Clash 等分流客户端，是目前兼顾速度、稳定性与解锁的最佳方案**。
